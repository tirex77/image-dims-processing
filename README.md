# Image Generator — Автоматическое нанесение размеров на изображения товаров

Проект для автоматической обработки изображений товаров: удаление фона, центрирование, нанесение размерных линий (L, W, H) и дисклеймера.

## 📋 Возможности

- **Удаление фона** — автоматическое удаление фона с помощью AI (rembg)
- **Формат 3:4** — приведение изображений к стандартному размеру 900×1200 пикселей
- **Размерные линии** — автоматическое нанесение стрелок с размерами:
  - **L** (Длина) — горизонтальная линия под объектом
  - **H** (Высота) — вертикальная линия справа со стрелкой
  - **W** (Глубина/Ширина) — диагональная линия в перспективе
- **Дисклеймер** — добавление текста о комплектации внизу изображения
- **Пакетная обработка** — обработка всех изображений из папки `input`

## 📁 Структура проекта

```
├── config.py           # Конфигурация: размеры, шрифты, текст дисклеймера
├── utils.py            # Утилиты: поиск изображений, подготовка (удаление фона)
├── processor.py        # Отрисовка размеров и дисклеймера
├── add_dim_arrows.py   # Демонстрационный скрипт для одиночной обработки
├── add_dims_batch.py   # Пакетная обработка изображений
├── main.py             # Точка входа
├── test_processor.py   # Тесты процессора
├── test_utils.py       # Тесты утилит
└── Montserrat-Light.ttf # Шрифт для отрисовки
```

## ⚙️ Установка

### Требования

- Python >= 3.13
- uv (менеджер пакетов)

### Шаги установки

```bash
# Клонировать репозиторий
cd /workspace

# Установить зависимости через uv
uv sync
```

## 🚀 Использование

### Одиночная обработка

```bash
python add_dim_arrows.py
```

Обработает изображение `input/100003.jpg` и сохранит результат в `result_step_by_step.jpg`.

### Пакетная обработка

```bash
python add_dims_batch.py
```

1. Поместите исходные изображения в папку `input/`
2. Запустите скрипт
3. Результаты появятся в папке `output/` с суффиксом `_21x15x8.png`

### Настройка параметров

Отредактируйте `config.py` для изменения:

```python
IMAGE_SIZE = (900, 1200)          # Размер выходного изображения
DIMENSIONS = {"L": 21, "W": 15, "H": 8}  # Размеры товара
DISCLAIMER_TEXT = "..."           # Текст дисклеймера
FONT_PATH = "Montserrat-Light.ttf" # Путь к шрифту
```
